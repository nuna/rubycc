# examples — マイルストーンごとのサンプル C プログラム

各マイルストーン完了時点の rubycc でビルドできる C ソースを `m<N>/` に残す。
「その時点で何ができるか」を実行可能な形で示すドキュメントであり、
`test/test_examples.rb` が全サンプルを gcc と差分比較(終了コード + 標準出力)
するため、機能追加でサンプルが壊れればテストが検出する。

## 運用

- マイルストーン完了時に、そのマイルストーンの代表機能を使うサンプルを
  `examples/m<N>/` へ追加して確定する(進行中のマイルストーンのディレクトリには
  実装済み機能の範囲で随時追加してよい)。
- 各サンプルの先頭コメントに「何を実演するか」を書く。
- サンプルは追加後に変更しない(後続ステップでも常にビルドできることが不変条件)。

## ビルド方法(M1 時点)

コンパイルは rubycc、リンクはシステムの gcc(自作リンカは M2)。

```sh
ruby -Ilib exe/rubycc -o fizzbuzz.o examples/m1/fizzbuzz.c
gcc -o fizzbuzz fizzbuzz.o
./fizzbuzz
```

## m1(進行中 — Step 16 時点)

| ファイル | 実演する機能 |
|---|---|
| `fizzbuzz.c` | ループ・剰余・if/else 連鎖・ローカル配列・ポインタ演算・外部 `puts` 呼び出し・手書き整数 10 進化 |
| `vowels.c` | switch/case/default とフォールスルー(Step 16)・文字列走査 |
| `list.c` | struct・ポインタ・ヌルポインタ定数とポインタ条件式(Step 14)による NULL 終端連結リスト |
| `bits.c` | ビット演算・シフト(Step 15)・goto による多重ループ脱出(Step 16) |
